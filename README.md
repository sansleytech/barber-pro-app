# barber-pro-app
Barber Pro es una plataforma online integral para barberías que facilita la gestión de citas, pagos, perfiles de barberos, inventario y reseñas en un solo lugar. Con un panel administrativo moderno y accesible desde web y móvil, digitaliza la experiencia, optimiza procesos y conecta clientes con barberos de forma ágil y segura.
